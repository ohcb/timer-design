# CUB3 프로젝트 설명서

## 프로젝트 개요

CUB3는 스피드큐빙을 위한 고급 큐브 타이머 및 분석 플랫폼이다.

기본적인 스톱워치 기능뿐만 아니라,
사용자의 솔브 기록을 저장하고 관리하며,
세션별 분석, 통계 계산, 스크램블 관리, 알고리즘 학습 기능까지 확장하는 것을 목표로 한다.

최종 목표는 단순한 타이머 앱이 아니라,
큐버들이 연습 데이터를 관리하고 성장 과정을 분석할 수 있는 플랫폼을 만드는 것이다.

현재 개발 방향:

- 모바일/태블릿: 대회장에서 빠르게 기록하는 용도
- 데스크톱: 집에서 장시간 연습하고 분석하는 메인 환경

두 환경은 같은 데이터를 사용하지만 UI 구조와 사용 목적은 다르게 설계한다.

# 개발 철학

## 기능과 UI의 분리

각 기능은 독립적인 모듈로 관리한다.

하나의 JS 파일에 모든 기능을 넣는 방식은 사용하지 않는다.

예를 들어:

나쁜 구조:

timer.js

- 타이머
- 기록 저장
- 세션 관리
- 통계 계산
- 스크램블 생성
- 설정 관리

모든 기능이 하나의 파일에 들어가는 구조.


좋은 구조:

timer.js

- 시간 측정
- 시작/정지
- 타이머 UI 업데이트


storage.js

- 데이터 저장
- 데이터 불러오기
- 삭제
- 백업


stats.js

- 평균 계산
- PB 계산
- WCA 통계 계산


sessionManager.js

- 세션 생성
- 세션 변경
- 현재 세션 관리


scramble.js

- 스크램블 요청
- 스크램블 관리


이런 방식으로 역할을 분리한다.
